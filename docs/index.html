BEFORE YOU DROP IN

Your copy.
Your assets.
Your instance.

The download contains integration software, the local companion, a validator and installation instructions. It contains no BO2 art, audio, animations, Minecraft binaries, Nuketown world, or third-party skins.

  1. Prepare Minecraft

    Use your own authenticated Minecraft Java account. Create a separate 1.20.1 instance with Fabric, Java 17 and Fabric API 0.92.2+1.20.1.

  2. Prepare your local assets

    You need the tested converted resource format listed in the asset manifest. Raw PC BO2 folders are not supported yet. The conversion pipeline was developed against Xbox zone data. No asset downloads are provided here.

  3. Install into the separate instance

    Extract the download and run its Python 3.10+ installer with your instance, converted resources and runtime paths. It validates required files before installation. Extra character files are optional. See the full guide for commands.

  4. Bring the compatible Nuketown world

    Obtain the Minecraft map independently. The current spawn contract expects the tested layout near overworld coordinates 1633, 20, −784. Other layouts need their spawn data regenerated.

  5. Start the companion, then Minecraft

    Run Start-Companion.cmd, add the generated JVM arguments to your Fabric profile, and launch through your normal Minecraft launcher. Press P to open the lobby.
